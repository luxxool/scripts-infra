
# SB4-Scripts-luxxool

Le Script installe 4 éditeurs en ligne de commande afin de pouvoir faire sur une même machine des tests et des commparaisons :

## les Editeurs
* The Nice Editor , taper ``ne  <file name>``
* GNU Emacs , taper: ``emacs  <file name>``
* Micro , taper ``mc  <file name>``
* Helix , taper ``helix  <file name>``

et 
## Midnight Commander
 * mcedit, taper :``mcedit  <file name>`` pour editer
 *  ou juste ``mc`` et naviguer dans l'arboressence des fichiers avec une interface plus graphique !
