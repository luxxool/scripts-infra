# scripts-infra

Mes scripts d'administration système, écrits pendant la saison Scripting.
Un dossier par langage, un script par tâche.

## Contenu

| Script | Rôle |
|---|---|
| `install-editor-toolset.sh` | Installe des editeurs en ligne de commande |

## Utilisation

```bash
./bash/install-edittor-toolset.sh
```

```powershell
.\powershell\info-systeme.ps1
```

## Prérequis

- Bash, testé sur Debian 12 ou 13 (Trixie)
- PowerShell 5.1 ou supérieur pour les scripts `.ps1`
- Droits de lecture sur les dossiers analys
